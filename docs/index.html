StardewParable

"Esta é a história de um fazendeiro chamado..."

StardewParable é um mod focado em narrativa para Stardew Valley que se recusa a observar silenciosamente suas escolhas rurais questionáveis. Ele rastreia todas as suas ações — desde plantar cherívias até fuçar no lixo alheio — e usa uma Inteligência Artificial para gerar um monólogo sarcástico julgando o seu dia.

O que a IA observa?

🎮 Rastreamento Preciso

O mod sabe quando você planta, colhe, mina ou quando coloca uma cerca exatamente no lugar errado. 100% integrado ao inventário do jogo.

🧠 Memória de Continuidade

O Narrador não esquece os dias anteriores. Ele usará seus erros passados como munição para os julgamentos futuros (Graças ao contexto da IA).

🔊 Voz Text-to-Speech

Suporte integrado para a API do ElevenLabs para que as broncas sejam verbalizadas com elegância. Ou use a voz robótica local, se preferir o caos.

📊 Dashboard Web

Acompanha um painel interativo (Gradio) no backend. Lá você monitora os logs em tempo real e pode até escrever prompts customizados para testar a paciência da IA.
