StardewParable

"A vida na fazenda nunca foi tão observada."

StardewParable é um mod narrativo para Stardew Valley que se recusa a observar silenciosamente suas escolhas rurais questionáveis. Ele rastreia todas as suas ações — desde plantar cherívias até fuçar no lixo alheio — e usa uma Inteligência Artificial avançada para gerar um monólogo sarcástico, julgando cada detalhe do seu dia.

✨ O que a IA observa?

🎮 Rastreamento de Gameplay Detalhado

Registra automaticamente e com precisão: Ações agrícolas (plantio, colheita, rega), Colocação de móveis/baús, Uso de ferramentas/armas, Mineração/combate, Pesca, Interações com NPCs, Crafting e vendas. 100% integrado ao inventário do jogo.

🧠 Memória de Continuidade (IA)

O Narrador não esquece os dias anteriores. Ele usa seus erros passados como munição para julgamentos futuros, mantendo uma coesão narrativa profunda e um senso de inevitabilidade.

🔊 Integração de Voz (TTS)

As histórias geradas são lidas em voz alta. Suporte nativo para ElevenLabs e fallback para serviços TTS locais, garantindo que o julgamento seja ouvido com clareza.

📊 Dashboard Interativo (Gradio)

Painel web integrado ao backend. Permite monitorar logs em tempo real das ações enviadas, acompanhar o histórico de contexto da IA e testar narrativas customizadas diretamente pelo navegador.

🏗 Arquitetura e Instalação

⚙️ Requisitos

  • Stardew Valley
  • SMAPI e Generic Mod Config Menu (GMCM)
  • Python 3.8+
  • Chave API LLM (OpenAI/Groq, etc.) ou Serviço TTS Local

🚀 Instalação do Backend

Na raiz do projeto, instale as dependências e execute o servidor:

cd backend
pip install -r requirements.txt

Configure seu arquivo `.env` e execute:

uvicorn main:app --reload --port 8000
